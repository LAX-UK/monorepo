# Account banner and sale bottom bar

Illustrations with mocked data (no real people), at 1440 and 375 px, light and dark. They are static
mock-ups of the copy and layout, not captures of the running app. `before-*` shows "Account in
review" with a Register button for a bidder whose registration and identity check are approved;
`after-*` shows the banner naming what is held and the bar offering View lots.
