# UX audit, 18 November 2026: staff admins

Scope: Bid admin (`apps/web` under `/admin`) and LAX Admin (`apps/shop-admin`), compared with each other
and with the staff kit (`packages/staff-ui`). This audit only reads code. It checks the work against
`docs/design/staff-design-standard.md` (rule IDs such as TBL-8 and FBK-7), the LAX colour rule, the
form-errors rule, the `@auction/datetime` date style and sentence case. Items already known
(the LAX Admin favicon redirect, missing LAX Account favicons, no LAX mark in the staff top bar, and
`/favicon.ico` 404s) are not repeated.

How to read the evidence column:

- Bid paths start from `apps/web/src/`.
- LAX paths start from `apps/shop-admin/src/`.
- Kit paths start from `packages/staff-ui/src/`.
- Anything else is a full repository path.
- "verify on test" means the code points to the problem but the result should be confirmed on the
  test environment.

**Top three problems**

1. **"Confirm it's you" works differently in different places.** Most Bid people and admin actions,
   including role changes, use an app-local path. It shows a toast, then sends staff to sign in
   without a dialog, and anything typed in the open dialog is lost. LAX's main Refund and
   "Retry refund" have no step-up dialog at all, while the kit's `StepUpDialog` is used elsewhere in
   both apps. See STF-1 to STF-4.
2. **The same list or record behaves differently in each admin.**
   - LAX has no record pager, no ⌘K record search and almost no loading states.
   - Clients, artists, disputes and enquiries offer different filters, sorting and export in each
     admin.
   - Queue rows link back to the panel instead of the record page.
   - 10 lists still use `onRowOpen` instead of real links. LAX From Zoho does the same but is
     wrongly marked as compliant.

   See STF-5 to STF-20.
3. **Formatting and feedback do not go through the kit.**
   - Bid has its own date, relative-time, money and toast helpers. They use the server or browser
     time zone instead of London, drop Undo actions and use other toast durations.
   - LAX uses `formatGbp` and a forked `StaffFormDialog`.
   - Status tones disagree: "Refunded" appears grey, blue or green.
   - Errors that staff must act on often appear only in toasts.

   See STF-21 to STF-45.
