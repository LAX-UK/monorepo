# UX audit, 18 Nov 2026: type, colour, theming and motion

Read-only audit of LAX Bid (`apps/web`: public site, client workspace, Bid admin), LAX Shop, lax.art, LAX Account, LAX Admin, hosted sign-in (`packages/auth`) and the shared kits (`packages/ui`, `staff-ui`, `branding`, `marketing-ui`, `email`). Each element was compared across the products. No product code was changed. Already-known items (LAX Admin favicons, no Account `public/favicons`, no LAX mark in the staff top bar, `/favicon.ico` 404) are not repeated.

**Top 3 problems**

1. **Bid still has three accents besides navy, and some are unreadable.** Gold, "accent blue" and "lot orange" tint icons, pills, warning bands and live states. Orange text on its own tint is 2.87:1, which fails WCAG AA (TCM-1, TCM-2, TCM-3).
2. **The shared palette is not one palette.** The same field error is drawn in four reds. Body text uses three near-blacks and two dark-mode creams. Field edges have three greys. Bid admin and LAX Admin render the same `@auction/ui` controls in different dark surfaces (TCM-4 to TCM-8).
3. **Type and motion each have more than one scale.** The same page title is 20, 24/28, 24–30, 30/36 or 36–60px depending on the product. Words go down to 8.8px. Bid shouts in capitals while Shop and lax.art cancel the same kit classes. Durations are mostly literal `duration-150/200/300` rather than `--lax-motion-*` tokens. Reduced motion is handled four different ways (TCM-12 to TCM-15, TCM-20 to TCM-26).
