# Staff gaps: mockups

Static, illustrative mockups for `docs/design/staff-gaps-delivery-zoho-alerts.md` (GAP-47, GAP-18,
LA-3). Not built from the staff-ui kit; the kit components are the source of truth. All names and
addresses are made up.

- `index.html`: the proposed Bid admin Deliveries list ("Waiting for a price" tab) with its queue
  panel, plus every status badge proposed in the doc (D2 delivery, Z2 Zoho, L2 release alerts).
- `deliveries-{width}-{theme}.png`: viewport captures at 1440 x 1000 and 375 x 812, light and dark.
  No horizontal scroll at 375 px.
